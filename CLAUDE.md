# CLAUDE.md

Use [AGENTS.md](AGENTS.md) as the canonical project instructions for this repo.

Short version:

- Use npm only; keep `package-lock.json` as the only package-manager lockfile.
- `npm run dev` starts the Astro local development server.
- Run `npm run audit:repo` before broad cleanup or metadata/navigation changes.
- Read [docs/design-baseline.md](docs/design-baseline.md) before layout or visual changes.
